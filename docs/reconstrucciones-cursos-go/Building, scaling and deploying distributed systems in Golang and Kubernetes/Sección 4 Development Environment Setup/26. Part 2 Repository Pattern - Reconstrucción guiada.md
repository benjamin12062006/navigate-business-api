## Objetivo de la lección

Completar un recorrido ejecutable desde `main` hasta un almacenamiento en memoria pasando por una capa de servicio.

## Fase 1 — Dominio y contratos

Procedencia: E1.

```go
package domain

import (
	"context"
	"time"

	"go.mongodb.org/mongo-driver/bson/primitive"
)

type RideFareModel struct {
	ID                primitive.ObjectID
	UserID            string
	PackageSlug       string
	TotalPriceInCents float64
	ExpiresAt         time.Time
}

type TripModel struct {
	ID       primitive.ObjectID
	UserID   string
	Status   string
	RideFare *RideFareModel
}

type TripRepository interface {
	CreateTrip(context.Context, *TripModel) (*TripModel, error)
}

type TripService interface {
	CreateTrip(context.Context, *RideFareModel) (*TripModel, error)
}
```

## Fase 2 — Repository en memoria

Procedencia: E2.

```go
package repository

import (
	"context"

	"example/internal/domain"
)

type InMemoryRepository struct {
	trips map[string]*domain.TripModel
	fares map[string]*domain.RideFareModel
}

func NewInMemoryRepository() *InMemoryRepository {
	return &InMemoryRepository{
		trips: make(map[string]*domain.TripModel),
		fares: make(map[string]*domain.RideFareModel),
	}
}

func (r *InMemoryRepository) CreateTrip(
	_ context.Context,
	trip *domain.TripModel,
) (*domain.TripModel, error) {
	r.trips[trip.ID.Hex()] = trip
	return trip, nil
}
```

## Fase 3 — Servicio

Procedencia: E3.

```go
package service

import (
	"context"

	"example/internal/domain"
	"go.mongodb.org/mongo-driver/bson/primitive"
)

type Service struct {
	repository domain.TripRepository
}

func NewService(repository domain.TripRepository) *Service {
	return &Service{repository: repository}
}

func (s *Service) CreateTrip(
	ctx context.Context,
	fare *domain.RideFareModel,
) (*domain.TripModel, error) {
	trip := &domain.TripModel{
		ID:       primitive.NewObjectID(),
		UserID:   fare.UserID,
		Status:   "pending",
		RideFare: fare,
	}
	return s.repository.CreateTrip(ctx, trip)
}
```

## Fase 4 — Composición

Procedencia: E4.

```go
package main

import (
	"context"
	"log"
	"time"

	"example/internal/domain"
	"example/internal/infrastructure/repository"
	"example/internal/service"
)

func main() {
	repo := repository.NewInMemoryRepository()
	svc := service.NewService(repo)

	trip, err := svc.CreateTrip(context.Background(), &domain.RideFareModel{UserID: "42"})
	if err != nil {
		log.Fatal(err)
	}
	log.Printf("trip: %+v", trip)

	for {
		time.Sleep(time.Second)
	}
}
```

`example` sustituye al módulo del repositorio del curso, que la transcripción no conserva de forma estable. El bucle es temporal y se elimina cuando existe un servidor real.

## Código final completo de la lección

El código de las fases 1 a 4 constituye el estado final reconstruido. En un proyecto ejecutable, cada bloque debe guardarse bajo su paquete correspondiente.

## Resumen mental

`main` elige `InMemoryRepository`; `Service` solo conoce `TripRepository`; el futuro cambio a MongoDB no altera el contrato ni la lógica de creación del viaje.
