## Objetivo de la lección

Convertir separación de responsabilidades en dependencias Go explícitas y sustituibles.

## Fase 1 — Definir el contrato donde lo necesita la lógica

Procedencia: E1, E2.

```go
package user

import "context"

type User struct {
	ID   int64
	Name string
}

type Repository interface {
	Create(ctx context.Context, user *User) error
}
```

## Fase 2 — Implementar el acceso a datos fuera del servicio

Procedencia: E2.

```go
package postgres

import (
	"context"
	"database/sql"

	"example/internal/user"
)

type UserRepository struct {
	db *sql.DB
}

func NewUserRepository(db *sql.DB) *UserRepository {
	return &UserRepository{db: db}
}

func (r *UserRepository) Create(ctx context.Context, u *user.User) error {
	_, err := r.db.ExecContext(ctx, `INSERT INTO users (name) VALUES ($1)`, u.Name)
	return err
}
```

`example` es un módulo neutral añadido para que la reconstrucción sea legible; la transcripción no conserva el módulo exacto.

## Fase 3 — Orquestar reglas en el servicio

Procedencia: E1, E3.

```go
package user

import (
	"context"
	"errors"
	"strings"
)

type Service struct {
	repository Repository
}

func NewService(repository Repository) *Service {
	return &Service{repository: repository}
}

func (s *Service) Register(ctx context.Context, name string) (*User, error) {
	name = strings.TrimSpace(name)
	if name == "" {
		return nil, errors.New("name is required")
	}

	u := &User{Name: name}
	if err := s.repository.Create(ctx, u); err != nil {
		return nil, err
	}
	return u, nil
}
```

## Fase 4 — Componer en `main`

Procedencia: E3.

```go
repository := postgres.NewUserRepository(db)
service := user.NewService(repository)
handler := httpapi.NewUserHandler(service)
```

## Código final completo de la lección

Los archivos completos reconstruidos están en las fases 1 a 3; `main` conserva solo la composición porque el transporte concreto no aparece completo en la transcripción.

## Resumen mental

El servicio conoce una capacidad (`Repository`), no una tecnología. `main` elige la implementación y el transporte recibe el servicio ya compuesto.
