## Fase 1 — Modelos y repository

Procedencia: E1, E3, E4.

```go
type Role struct {
	ID          int64
	Name        string
	Level       int
	Description string
}

type User struct {
	ID   int64
	Role Role
}

type Roles interface {
	ByName(ctx context.Context, name string) (*Role, error)
}
```

```go
func (s *RoleStore) ByName(ctx context.Context, name string) (*Role, error) {
	var role Role
	err := s.db.QueryRowContext(ctx, `
		SELECT id, name, level, description
		FROM roles
		WHERE name = $1
	`, name).Scan(&role.ID, &role.Name, &role.Level, &role.Description)
	return &role, err
}
```

## Fase 2 — Comprobar precedencia

Procedencia: E3.

```go
func (app *Application) hasRolePrecedence(
	ctx context.Context,
	user *User,
	requiredRole string,
) (bool, error) {
	required, err := app.store.Roles.ByName(ctx, requiredRole)
	if err != nil {
		return false, err
	}
	return user.Role.Level >= required.Level, nil
}
```

## Fase 3 — Middleware de ownership

Procedencia: E1-E4.

```go
func (app *Application) CheckPostOwnership(requiredRole string) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			user := userFromContext(r)
			post := postFromContext(r)

			if post.UserID == user.ID {
				next.ServeHTTP(w, r)
				return
			}

			allowed, err := app.hasRolePrecedence(r.Context(), user, requiredRole)
			if err != nil {
				http.Error(w, http.StatusText(http.StatusInternalServerError), http.StatusInternalServerError)
				return
			}
			if !allowed {
				http.Error(w, http.StatusText(http.StatusForbidden), http.StatusForbidden)
				return
			}
			next.ServeHTTP(w, r)
		})
	}
}
```

## Fase 4 — Políticas por ruta

Procedencia: E2, E5.

router.With(app.CheckPostOwnership("moderator")).Patch("/posts/{postID}", updatePost)

Los bloques anteriores reconstruyen los símbolos esenciales. La consulta que carga usuarios debe unir `users.role_id = roles.id` y escanear el rol para que la comparación use datos actuales.

## Resumen mental
