## Objetivo de la lección

Transformar un bearer token válido en una identidad actual del sistema disponible para los handlers.

## Fase 1 — Validación criptográfica y semántica

Procedencia: E2.

```go
func (a *JWTAuthenticator) ValidateToken(raw string) (*jwt.Token, error) {
	return jwt.Parse(raw, func(token *jwt.Token) (any, error) {
		if _, ok := token.Method.(*jwt.SigningMethodHMAC); !ok {
			return nil, fmt.Errorf("unexpected signing method: %s", token.Method.Alg())
		}
		return []byte(a.secret), nil
	},
		jwt.WithExpirationRequired(),
		jwt.WithAudience(a.audience),
		jwt.WithIssuer(a.issuer),
		jwt.WithValidMethods([]string{jwt.SigningMethodHS256.Alg()}),
	)
}
```

## Fase 2 — Clave tipada para contexto

Procedencia: E3.

```go
type contextKey string

const userContextKey contextKey = "user"

func userFromContext(r *http.Request) *User {
	user, _ := r.Context().Value(userContextKey).(*User)
	return user
}
```

## Fase 3 — Middleware bearer

Procedencia: E1-E3.

```go
func (app *Application) TokenAuth(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		parts := strings.SplitN(r.Header.Get("Authorization"), " ", 2)
		if len(parts) != 2 || parts[0] != "Bearer" {
			http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
			return
		}

		token, err := app.authenticator.ValidateToken(parts[1])
		if err != nil || !token.Valid {
			http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
			return
		}

		claims, ok := token.Claims.(jwt.MapClaims)
		if !ok {
			http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
			return
		}
		userID, err := strconv.ParseInt(fmt.Sprint(claims["sub"]), 10, 64)
		if err != nil {
			http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
			return
		}

		user, err := app.store.Users.ByID(r.Context(), userID)
		if err != nil {
			http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
			return
		}

		ctx := context.WithValue(r.Context(), userContextKey, user)
		next.ServeHTTP(w, r.WithContext(ctx))
	})
}
```

## Fase 4 — Consumir identidad sin otra consulta

Procedencia: E4.

```go
func (app *Application) createPostHandler(w http.ResponseWriter, r *http.Request) {
	user := userFromContext(r)
	// user.ID identifica al autor autenticado.
}
```

## Código final completo de la lección

Los cuatro bloques anteriores forman el núcleo final. El router puede aplicar `TokenAuth` a un grupo de rutas y dejar públicas únicamente registro, activación y emisión de token.

## Distinción importante

Esta middleware autentica: confirma quién es el usuario y carga su estado actual. Todavía no decide si puede modificar un recurso ajeno; esa es responsabilidad de autorización.

## Resumen mental

Validar firma no basta: también se fijan algoritmo, expiración, issuer y audience. Después se recupera al usuario vigente y se transporta por contexto.
