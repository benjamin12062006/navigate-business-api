## Objetivo de la lección

Proteger una superficie operativa con una middleware pequeña y conforme al protocolo HTTP.

## Fase 1 — Configuración

Procedencia: E4.

```go
type BasicAuthConfig struct {
	Username string
	Password string
}
```

## Fase 2 — Middleware

Procedencia: E1, E2.

```go
func BasicAuth(config BasicAuthConfig) func(http.Handler) http.Handler {
	return func(next http.Handler) http.Handler {
		return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
			header := r.Header.Get("Authorization")
			parts := strings.SplitN(header, " ", 2)
			if len(parts) != 2 || parts[0] != "Basic" {
				basicUnauthorized(w)
				return
			}

			decoded, err := base64.StdEncoding.DecodeString(parts[1])
			if err != nil {
				basicUnauthorized(w)
				return
			}

			credentials := strings.SplitN(string(decoded), ":", 2)
			if len(credentials) != 2 ||
				credentials[0] != config.Username ||
				credentials[1] != config.Password {
				basicUnauthorized(w)
				return
			}

			next.ServeHTTP(w, r)
		})
	}
}
```

## Fase 3 — Challenge correcto

Procedencia: E3.

```go
func basicUnauthorized(w http.ResponseWriter) {
	w.Header().Set("WWW-Authenticate", `Basic realm="restricted", charset="UTF-8"`)
	http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
}
```

## Fase 4 — Aplicarlo solo donde corresponde

Procedencia: E1, E3.

```go
router.With(BasicAuth(config)).Get("/health", healthHandler)
```

## Código final completo de la lección

Los tres bloques anteriores forman una implementación autónoma. El router concreto puede variar; la lección usa la capacidad de encadenar middleware del router.

## Límites

- Base64 codifica; no cifra. El transporte debe usar HTTPS.
- Comparar secretos directamente refleja la lección. Una adaptación sensible puede usar comparación en tiempo constante.
- Las credenciales operativas no deben tener valores predeterminados públicos en producción.

## Resumen mental

Basic auth es apropiado para pocos consumidores controlados. El `WWW-Authenticate` produce el challenge del navegador y `401` indica que la identidad no fue aceptada.
