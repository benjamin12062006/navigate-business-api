## Objetivo de la lección

Intercambiar credenciales válidas por un JWT de vida limitada sin acoplar el handler a la implementación criptográfica.

## Fase 1 — Contrato y configuración

Procedencia: E3, E4.

```go
type Authenticator interface {
	GenerateToken(jwt.Claims) (string, error)
	ValidateToken(string) (*jwt.Token, error)
}

type TokenConfig struct {
	Secret   string
	Issuer   string
	Audience string
	Expiry   time.Duration
}
```

## Fase 2 — Implementación JWT

Procedencia: E3.

```go
type JWTAuthenticator struct {
	secret   string
	issuer   string
	audience string
}

func NewJWTAuthenticator(secret, issuer, audience string) *JWTAuthenticator {
	return &JWTAuthenticator{secret: secret, issuer: issuer, audience: audience}
}

func (a *JWTAuthenticator) GenerateToken(claims jwt.Claims) (string, error) {
	token := jwt.NewWithClaims(jwt.SigningMethodHS256, claims)
	return token.SignedString([]byte(a.secret))
}
```

## Fase 3 — Payload y respuesta uniforme

Procedencia: E1, E2.

```go
type tokenPayload struct {
	Email    string `json:"email"`
	Password string `json:"password"`
}

type tokenResponse struct {
	Token string `json:"token"`
}
```

El handler debe responder `401 Unauthorized` tanto si el email no existe como si el password no coincide. Una respuesta distinta permitiría inferir qué cuentas existen.

## Fase 4 — Claims mínimos

Procedencia: E4.

```go
now := time.Now()
claims := jwt.MapClaims{
	"sub": strconv.FormatInt(user.ID, 10),
	"exp": now.Add(config.Expiry).Unix(),
	"nbf": now.Unix(),
	"iat": now.Unix(),
	"iss": config.Issuer,
	"aud": config.Audience,
}

token, err := authenticator.GenerateToken(claims)
```

La lección evita introducir roles o permisos en el token para reducir información obsoleta.

## Fase 5 — Esqueleto del handler

Procedencia: E1-E4.

```go
func (app *Application) createTokenHandler(w http.ResponseWriter, r *http.Request) {
	var payload tokenPayload
	if err := json.NewDecoder(r.Body).Decode(&payload); err != nil {
		http.Error(w, "invalid payload", http.StatusBadRequest)
		return
	}

	user, err := app.store.Users.ByEmail(r.Context(), payload.Email)
	if err != nil || !user.Password.Matches(payload.Password) {
		http.Error(w, http.StatusText(http.StatusUnauthorized), http.StatusUnauthorized)
		return
	}

	now := time.Now()
	claims := jwt.MapClaims{
		"sub": strconv.FormatInt(user.ID, 10),
		"exp": now.Add(app.config.Expiry).Unix(),
		"nbf": now.Unix(),
		"iat": now.Unix(),
		"iss": app.config.Issuer,
		"aud": app.config.Audience,
	}
	token, err := app.authenticator.GenerateToken(claims)
	if err != nil {
		http.Error(w, http.StatusText(http.StatusInternalServerError), http.StatusInternalServerError)
		return
	}
	json.NewEncoder(w).Encode(tokenResponse{Token: token})
}
```

`Password.Matches` representa el comparador de hash construido anteriormente; su implementación no pertenece a esta lección.

## Resumen mental

El endpoint autentica una sola vez, emite claims mínimos y delega la firma. La uniformidad del `401` protege contra enumeración de usuarios.
